# VIDNESD · Cardverse

Коллекционная игра с бесплатными виртуальными VC Coins, кейсами карточек, ежедневными наградами, заданиями, профилями и таблицей лидеров. **Нет реальных ставок, платежей, денежных призов или вывода средств.**

## Запуск

1. Создайте Firebase Web App в проекте `casespin-web` и скопируйте **публичный** `firebaseConfig` в `firebase-config.js`.
2. В Firebase Authentication включите Email/Password и настройте домен в Authorized domains.
3. Включите Firestore (production mode).
4. Установите Node.js LTS и Firebase CLI: `npm i -g firebase-tools`; выполните `firebase login`.
5. В каталоге `functions` выполните `npm install`.
6. Из корня проекта: `firebase emulators:start` для локальной проверки. Для работы с эмуляторами в клиенте включите `?emulator=1` на localhost.
7. Для публикации Cloud Functions потребуется Firebase Blaze с биллингом. После настройки: `firebase deploy --only functions,firestore,hosting`.

Веб-страница не выполняет игровые операции без настроенных Cloud Functions. Результат кейса, стоимость, баланс и выдача наград определяются только сервером. Для нового пользователя сервер создаёт профиль при первом вызове bootstrap после подтверждения email.

## Системы

- 16 кейсов, 32 карточки, 4 редкости, анимация открытия и эффекты.
- Начальный бонус 1000 VC, ежедневная награда 150 VC, задания и уровни.
- Серверные транзакции Firestore и защита от повторных запросов (operationId).
- Публичный лидерборд по XP, персональный инвентарь.
- Строгие Firestore Rules, серверная валидация авторизации и подтверждённой почты.

## Безопасность

Не помещайте Admin SDK service account, API-секреты или приватные ключи в репозиторий. Настройте Firebase App Check перед публичным запуском, мониторинг затрат и лимиты бюджета. Firebase Blaze может создавать расходы. Никаких гарантий отсутствия злоупотреблений без внешнего аудита.
